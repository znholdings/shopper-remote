Shopper — Privacy Policy

Last updated: 13 September 2026

Shopper is a private, single-user tool. It was built by and for the owner of ZN Holdings LLC to run their own Amazon FBA resale business. It is not published to the Chrome Web Store, is not offered to anyone else, and has no users other than its owner. It handles only the owner's own data.

What it accesses, and why

  • Gmail — read only. Shopper reads order confirmation, shipping and delivery emails from retailers in the owner's own mailboxes, so that purchases can be matched to deliveries automatically instead of by hand. It never sends, replies to, modifies, labels or deletes mail.
  • Google Sheets — read and write. Shopper reads and writes the owner's own spreadsheets, which hold the purchase log and the inventory reconciliation it produces.

Where the data goes

  • It stays in the owner's own Google account and on the owner's own computer, in the browser's local storage.
  • The status of a purchasing run is copied to a private database (Supabase) controlled by the owner, so that the run can be monitored from the owner's phone. Access to it is restricted to the owner's own Google sign-in.
  • When Shopper's built-in parsers cannot read a retailer email, a short excerpt of that message may be sent to Anthropic's Claude API to extract the order number, quantity and delivery status. Nothing else is sent, and it is used only to read that one message.

What it does not do

  • No data is sold, rented, shared or transferred to anyone for advertising or any other purpose.
  • There is no analytics, tracking or profiling of any kind.
  • No other person's data is collected, because there are no other users.

Use of Google user data

Shopper's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used solely to provide the purchasing and inventory reconciliation features described above, and is never used for advertising, sold, or transferred to third parties except as needed to provide those features.

Keeping and deleting data

Data is kept for as long as the owner keeps using the tool. Removing the extension from Chrome deletes everything it stored locally. The spreadsheets and email remain in the owner's own Google account, under the owner's control, and can be deleted there at any time. Access can be revoked at any time from the owner's Google account permissions page.
